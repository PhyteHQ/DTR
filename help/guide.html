DTR // POB Network — User Guide

How to use the DTR Command Dashboard

DTR is the operations dashboard for our three Corsair player-owned bases (POBs) in Discovery Freelancer: Deterrence Sanctum, Ravenna Invicta and Fort Torrelavega. It shows live stock and credits, tracks maintenance supplies, calculates production and shipbuilding, plans trade routes and helps you write in-character forum posts. This guide walks through every screen.

00

Getting started

There is nothing to sign up for. Open the site and it connects to Darkstat, the public Discovery data service, to pull live data on our bases. Within a few seconds the uplink in the top right should read 3/3 NODES LIVE.

  1. Check the Overview. The first screen summarises all three bases: credits, free storage, the three maintenance supplies and any alerts.
  2. Open a base. Click a base card (or the SANCTUM, INVICTA, TORRELAVEGA tabs) to see its full inventory, production and, for Invicta, the shipyard.
  3. Use the tools. The main tabs at the top lead to TRADE ROUTES, FORUM and CALCULATOR.
TIP // Data refreshes by itself every 5 minutes. Press REFRESH or FORCE UPLINK if you want it right now.

Header & Darkstat uplink

The uplink box shows the connection state with a coloured dot:

  • Green — live data received (e.g. 3/3 NODES LIVE).
  • Amber — using cached data or still syncing.
  • Red — the uplink failed; the last good data is shown if available.

REFRESH requests new data immediately. The freshness text under the logo turns amber when data is older than 15 minutes and red after an hour.

Attention filter & calculator shortcut

ATTENTION · ONLY ISSUES hides everything that is fine and leaves only items that need action. The number on the button is the current count of issues. Click again to return to ALL NETWORK DATA. Your choice is remembered.

CALCULATOR · RECIPE COST jumps straight to the Recipe Cost Calculator from anywhere.

System check

SYSTEM · APP STATUS opens a diagnostics sheet covering the Darkstat uplink, connection, local storage, POB matches, recipe catalog, routes, app shell and update status. RUN CHECK re-tests, and COPY DIAGNOSTICS copies a report you can paste to an officer when something looks wrong.

Installing the app (phone or desktop)

DTR can be installed like an app. Press INSTALL · PHONE APP and follow the prompt; on iPhone use Safari's Share → Add to Home Screen. Once installed it opens full-screen and the app shell works offline.

When a new version is published you will see DTR UPDATE READY. Nothing reloads by itself — press UPDATE NOW when convenient.

02

POB Network: Overview

The Overview is the home screen of the POB Network tab. It answers “are our bases OK?” at a glance. The Network State box in the corner summarises it, for example ALL NODES NOMINAL or NODES ONLINE // ALERTS ACTIVE.

POB status cards

Each card shows:

  • Name, health % and location (region // system // sector // coordinates).
  • Credits and free storage.
  • ALLOY / FOOD / GOODS — current stock of the three maintenance supplies, coloured by status.
  • Facility conditions — how many alerts the base has.

Below the cards: Nodes Online, Total Credits across all bases (with change since the previous snapshot when available) and Active Alerts.

Uplink status panel

Shows the system clock, time of the latest sync, snapshot age, a countdown to the next automatic sync and whether the datalink is LIVE or CACHED. FORCE UPLINK fetches now.

Network Matrix

The matrix lines up important commodities (the maintenance supplies plus every base's pinned cargo) against all three bases so you can see where something is short and where it can be moved from. Each cell shows the quantity and a status such as OPERATIONAL or CRITICAL RESERVE.

Click any cell to open that base with that item highlighted in its inventory. On phones, swipe sideways to see all columns.

03

POB detail pages

Open a base with its sub-tab or by clicking its card. Every base page has the same sections; production and shipyard appear only where the base actually runs them.

  • Structural Integrity — base health bar and percentage.
  • Last Verified Sync — when this base's data was confirmed, and whether it is live or cached.
  • Base Credits / Free Storage — with the change since the previous snapshot.

Facility maintenance (Daily Operating Reserves)

Every POB consumes Basic Alloy, Food Rations and Consumer Goods. Each card shows stock, a bar against the base's configured minimum/maximum, and a state: NOMINAL / OPERATIONAL, LOW RESERVE or CRITICAL RESERVE. The badge on the right of the header sums it up (e.g. FACILITY NOMINAL or ACTION REQUIRED).

HOW LIMITS WORK // Bars and warnings use the minimum/maximum stock set on the base in-game. Only if the base reports no limits does DTR fall back to its own thresholds (critical below 2,500, low below 15,000).

Production modules

Each production card is one factory on the base. It shows the output per cycle, how many cycles the current stock can support (MAX CYCLES), the estimated yield, the input that will run out first (bottleneck), any byproducts and any catalysts (needed on site but not used up).

Invicta shipyard

Only Ravenna Invicta has a shipyard. Pick a hull at the top — Murmillo, Legate, Consul or Archon — and the panel shows what it takes to build one.

  • Materials for — how many complete ships current stock covers.
  • Bottleneck / Next ship — which component runs out first and how many more you need for the next build.
  • Est. component value — value of one ship's components. Shown only when every price is known.
  • Ship components table — per-ship requirement, POB stock, unit value and next-ship status (READY or the shortfall).
  • Build prerequisites — crew and blueprints that must be present but are not consumed.
PRICING // Bought-in components are valued at Invicta's buy price (EXTERNAL SUPPLY). Exotic Systems, which Invicta makes itself, are valued at Invicta's sell price (IN-HOUSE PRODUCTION). The figure is a component valuation, not a full manufacturing cost.

COST / CALCULATE 1 SHIP opens the hull's recipe in the Calculator. The last hull you selected is remembered.

Pinned cargo

Pin the commodities you care about so they appear at the top of the base page and in the Network Matrix. Each base has its own pins.

  1. Find the commodity in Base Inventory below.
  2. Click the ★ in the PIN column. It turns gold.
  3. Remove a pin by clicking the star again, or the × on the pinned card.

04

Trade Routes

Trade Routes finds profitable trade runs using live Discovery market prices, your ship's cargo, speed and docking class, and Corsair docking rights. Work top-to-bottom: choose a ship, set the flight plan, calculate, then open a route.

Step 1 — Choose your ship

  • Quick select favourites — three slots, by default Raba, Armicustos and Essedarius. Tap one to use it. Press the ★ on a slot to save the currently selected ship into it.
  • Selected ship — max cargo, cruise speed and docking type (Ring, Mid, Large). The badge shows whether the data is LIVE, CACHED or PRESET.
  • Available cargo — how much hold space you actually have free. Lower it if you are carrying other cargo. It cannot exceed the ship's max.

Search / change ship

Press SEARCH / CHANGE SHIP and type a name, Corsair nickname or internal ID. Aliases work too, e.g. Bulwark, Pilgrim, Raba.

Custom profile

Press CUSTOM PROFILE to enter a ship by hand: name, cargo capacity, cruise speed and docking class. Up to 30 profiles are saved on your device, and you can edit, delete or favourite them.

DOCKING CLASS // Choose the ship's real docking class. Large ships cannot use stations that only have rings or mid-size moorings, so a wrong class gives routes you cannot fly.

Step 2 — Flight plan

  • Starting base — defaults to Planet Crete (Omicron Gamma). Click it to search any other base or system. Bases your ship physically cannot dock at are not offered.
  • Route type — ONE WAY or ROUND TRIP (default; finds trades out and back).
  • Include POBs — off by default. Turn on to also trade with player bases.
  • Flying as Corsair — on by default. Uses Corsair ID docking rules (see Docking). Turn off if you fly another faction.

The summary line under the form restates your settings so you can check them before searching.

Step 3 — Calculate & read results

Press CALCULATE TRADE ROUTES ↗. The search runs in the background; ABORT SEARCH stops it. Changing the result ranking reorders the existing routes without clearing them.

With INCLUDE POBs enabled, calculating checks POB data age and updates stock, prices, credits and free storage when the snapshot is at least five minutes old. Current dashboard data is reused when available. NPC-only searches keep the loaded market snapshot. FORCE MARKET UPLINK refreshes the entire market manually.

Each result card shows Profit / Route, Profit / Hour, Flight time and the legs with what to buy and sell. Use Rank by to sort by $ / HOUR or TOTAL PROFIT. OPEN MANIFEST / ROUTE shows the full step-by-step route; SHOW MORE reveals alternatives.

ESTIMATES // Flight times are modelled (trade lanes counted at 2,500 m/s) and include the approach from your starting base. Prices move as other players trade, so check the market in game before buying. If you change ship or settings, the panel tells you to recalculate.

Docking rules & Corsair ID

With Flying as Corsair on, DTR uses the real Corsairs ID rep-hack data to predict where you can dock:

  • NPC bases require reputation above -0.55. An ID maximum or fixed reputation of exactly -0.55 is already no-dock. This excludes all Order bases with the Corsair ID, including Thebes, Taba and Akabat, as well as Lane Hacker bases such as Cochrane Depot (-0.70).
  • Bases where ID access or the selected ship's physical docking cannot be verified are excluded unless you tick Include unverified docks. Known denied bases and incompatible ship docks remain blocked with that option on.
  • A base being allowed means possible, not guaranteed — your personal reputation and private POB rules still apply.
  • Some bases are always blocked (e.g. no-dock Planet Manhattan).

With Corsair off, no ID check is done and you should verify access for your own faction yourself. Ship docking-class restrictions still apply. Unknown physical docking still requires Include unverified docks.

If docking metadata cannot be refreshed, the last valid ID rules and NPC owners are retained with a CACHED notice. The ID-rule date is shown separately from market prices. FORCE MARKET UPLINK retries the full refresh.

05

Recipe Cost Calculator

Work out what it costs to produce anything from Discovery's 292 base recipes, using the live prices at one of our bases.

  1. Search recipe — type a product or recipe name (e.g. food rations, reactor, wildcat gold). The first match is selected automatically; choose another in Selected recipe.
  2. Price source POB — pick Sanctum, Invicta or Torrelavega. Its BASE BUYS prices fill the material prices.
  3. Output quantity — how many items you want. DTR works out the cycles needed and the actual output.
  4. Read the quote — Total build cost and Cost / produced item, plus how many materials are priced.

Consumed materials table

  • Each input shows the amount required, POB stock, unit price, line cost and status (available, price/stock notice, missing / out of stock).
  • Override a price by typing in the unit price box. Manual prices are saved per base on your device. USE POB PRICE returns to the live price.
  • Items the base doesn't list show NOT LISTED and stay unpriced (—) until you enter a price — they are never counted as $0.
  • Where a recipe accepts alternative inputs, a material chooser appears. It automatically picks the cheapest available option; you can choose manually and switch back to automatic.

Catalyst requirements are listed separately: they must be on site but aren't consumed, so they are not added to the cost. A recipe fee card appears only if the recipe charges one. Some recipes are marked RESTRICTED // CORSAIR IFF NOT AUTHORIZED — those can't be produced on a Corsair base.

BACK TO NETWORK returns to the POB Network.

Forum Tools

The Forum tab has two tools; pick one with the buttons under the header: 01 FORUM COMPOSER and 02 AVATAR FRAME. Nothing here is posted for you or uploaded — you copy the result into the forum yourself.

Forum Composer (transmissions)

Writes an in-character Corsair transmission in the DTR style and turns it into forum BBCode.

Fields

  • Load saved sender — reuse a saved identity.
  • Sender ID, Role / signature title, Location, Recipient, Encryption.
  • Personal sender image (left) — optional URL to your character portrait or GIF.
  • Internal draft subject — only for organising drafts; never appears in the post.
  • Opening and Sign-off — optional.
  • Message — plain text or BBCode. **bold** and ## heading work too. The toolbar inserts Bold, Italic, Underline, Heading, Quote, Spoiler, Image, Link and List.
  • Visual settings — optional top banner and footer image URLs. The DTR serpent crest on the right is fixed.

Buttons

  • COPY BB CODE — copies the finished code.
  • SAVE DRAFT / LOAD DRAFT / DELETE DRAFT — named drafts on your device.
  • SAVE SENDER / REMOVE SENDER — reusable identities (includes the portrait URL).
  • CLEAR MESSAGE — empties the message text.

Your current text autosaves in the browser.

  1. Fill in the fields and write your message.
  2. Check it in Preview.
  3. Press COPY BB CODE, then paste into your Discovery forum post.
COPY NOT WORKING? // Some phones block clipboard access. DTR then switches to the BB CODE view and selects the code — long-press and copy it manually.

Avatar Frame tool

Puts your character portrait inside the official DTR border and exports a 200 × 233 px forum avatar.

  1. UPLOAD PORTRAIT — PNG, JPG or WebP up to 15 MB.
  2. Position it: drag the image, use the arrow buttons for fine moves, or set Zoom from 2% to 400%.
  3. FIT IMAGE shows the whole picture on a dark background; FILL FRAME covers the frame. RESET POSITION recentres.
  4. DOWNLOAD PNG saves the finished avatar. Upload it to an image host if the forum needs a URL.

Your image never leaves your device.

Using DTR on a phone

  • The layout stacks into one column; the main sections are reachable from the larger fixed navigation.
  • Inventory rows become cards with labelled values.
  • Swipe the Network Matrix sideways to see all bases.
  • The Forum composer shows WRITE / PREVIEW / BB CODE as separate tabs.
  • Install it to your home screen for a full-screen app (see Installing).
08

Data, privacy & offline

  • Where data comes from: base stock, prices, ships and markets come from the public Darkstat API for Discovery. Recipes come from Discovery's public game config.
  • Unknown stays unknown: a — means the value wasn't reported. DTR never treats it as zero.
  • Stored on your device only: last snapshot, your view, pins, manual prices, ship profiles and favourites, forum drafts and senders. Nothing is uploaded. Clearing site data resets them.
  • Offline: if the connection drops you'll see an OFFLINE MODE banner and the last verified data. Live telemetry resumes when you're back online.

FAQ & troubleshooting

The site says AWAITING DATA or UPLINK FAILED

Darkstat may be slow or down. Wait a moment and press REFRESH. If it continues, open SYSTEM, press RUN CHECK and send the COPY DIAGNOSTICS report to an officer.

Numbers don't match what I see in game

Darkstat updates periodically, so there is always a short delay. Check the snapshot age in the Uplink panel. Prices especially can change minute to minute.

Why does an item show — instead of 0?

— means the value wasn't reported. DTR deliberately doesn't guess, so you can tell “really empty” from “unknown”.

My pins disappeared

Pins are stored per base and per device/browser. Check you are on the same base and browser; clearing site data removes them.

Trade Routes found no routes

Try longer Max route time, more capital, Extended search depth, Include POBs, or a different start base. Also check Available cargo and the docking class of your ship.

A suggested route won't let me dock

Check Flying as Corsair, the ship's docking class and any CACHED docking notices. Use UPDATE NOW when an app update is ready, then recalculate. Personal reputation, private POB whitelists and in-game restrictions can still differ. Leave Include unverified docks off for the safest results.

The calculator total shows —

At least one material has no price at the selected base. Type a unit price for each NOT LISTED material, or choose a different price source POB.

COPY BB CODE did nothing

Your browser blocked the clipboard. Open the 03 BB CODE view, select all and copy manually.

The installed app looks old

Look for the UPDATE NOW prompt, or open SYSTEM and check APP UPDATE. Updating reloads the app with the latest version.
